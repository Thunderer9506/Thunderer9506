## <a id="about-me"></a>📝 About

Hey, I'm Shaurya Srivastava, a CS student who spends a lot of time thinking about how things work under the hood. Python is my language of choice, JavaScript shows up when the frontend demands it, and C++ only comes out when competitive programming is involved. I care about understanding systems at a fundamental level, and that curiosity is what keeps pulling me deeper into backend and software engineering. I'm currently building Git from scratch, not because it's required, but because understanding why something works is always more satisfying than just knowing that it does. When I run into a problem, I find a way through it, one way or another.

When I'm not coding, I'm watching movies or anime, playing video games, or hanging out with friends. I build projects that help me upskill and pick up something new along the way. I value depth over buzzwords and systems thinking over tutorials. Currently studying, building, and open to opportunities where the work actually matters.
